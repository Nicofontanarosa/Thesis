# Encrypted Traffic Parser ETP — Master’s Thesis

### Overview

This repository contains the code and research developed for my **<mark>Master’s Thesis</mark>**. The goal is to extract meaningful metadata from encrypted network traffic ( *TLS, VPN etc ...* ) and use it to automatically generate detection rules for nDPI. The approach combines handshake analysis, TCP/TLS fingerprinting, and flow correlation to identify unknown or unclassified protocols.

# 🤸 Quickstart

To get started with **nDPI Protocol Generator**, follow these steps:

## 1️⃣ Install nDPI

Before running this tool, make sure **nDPI** is installed and compiled on your system. You can follow the official instructions from the [nDPI GitHub repository](https://github.com/ntop/nDPI). Once nDPI is installed, you can use this tool for metadata extraction and rule generation

## 2️⃣ Run the Tool

There are two ways to use this project:

1. 🖥️ Graphical interface ( *recommended* )
2. 💻 Command-line mode

### 🖥️ Graphical Interface ( Textual-based UI )

- Install the textual library with `pip install textual`
- Then start the graphical interface with `python3 flow_viewer_textual.py`

In this version, the interface will ask for all required paths ( **PCAP file, nDPI root path, and output directory** ) through the GUI. <mark>!! you don’t need to type them in the terminal !!</mark>

### 💻 Command-Line Mode

- If you prefer the command line, run: `python3 debug.py <pcap_path> <ndpi_path> <output_folder> <proto_name>`

***Example:***

`python3 debug.py /downloads/application.pcapng /home/Nico/nDPI/ test/application Gioco`

- Parameters:

1. **<pcap_path>** → path to your `.pcap` or `.pcapng` file (e.g., /downloads/app.pcapng)
2. **<ndpi_path>** → main `directory` where nDPI is installed (e.g., /home/Nico/nDPI/)
3. **<output_folder>** → directory where analysis results and generated rules will be saved (e.g., test/app/)
4. **<proto_name>** → application name

# 3️⃣ ⚙️ How it works?

📂 Output Files

After running the tool, you’ll find all generated and intermediate files inside the `tmp/` directory.
Each file provides useful information about the analyzed traffic and the generated nDPI rules.

| File | Description |
|------|--------------|
| **final_output.json** | Contains all analyzed flows processed by the tool |
| **filtered_flows.json** | Includes only the flows that remained after the various filtering phases |
| **removed_flows.json** | Lists all flows removed from the initial traffic during preprocessing and filtering |
| **coverage.txt** | Displays the coverage percentage of the generated rule over the analyzed traffic |
| **rules.txt** | Contains the nDPI detection rules automatically generated by the system |
| **flows.txt** | Provides summary information about the flows analyzed |
| **stats.txt** | Includes general statistics about the analyzed traffic |
| **initialization.txt** | Logs initial configuration and environment details used during analysis |
| **log_risky_flows.txt** | Lists flows marked as risky by nDPI according to its internal risk assessment |
| **sni_stats.txt** | Shows statistics on all SNI values observed in the traffic, useful for identifying recurring domains or patterns |

> ⚠️ **Note:**  
> A copy of the following key files — **`final_output.json`**, **`rules.txt`**, and **`coverage.txt`** —  
> is also automatically saved inside the program’s **output directory** specified at runtime.
